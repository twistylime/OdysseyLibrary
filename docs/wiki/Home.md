# Odyssey Library

> Part of the Odyssey Suite · Minecraft 1.20.1 · Forge 47.4.28+ · **server-side only**

The core every Odyssey mod is built on. It owns the `/odyssey` command, the hub menu, live settings,
Odyssey Points, the Mailbox and the shared chest menus. Players never need to install anything.

![Odyssey hub: 6-row chest titled "Odyssey", player head and Points/Mailbox buttons in the top row, module icons below, admin tools in the bottom row](images/library-overview.png)

## Quick start
1. Put `OdysseyLibrary-1.20.1-<version>.jar` in the server's `mods/` folder (plus any Odyssey mods).
2. Start the server. Settings appear in `config/odyssey/`, data in `<world>/odyssey/`.
3. In game, type `/odyssey` to open the hub.
